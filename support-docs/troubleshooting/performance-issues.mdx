Performance issues can come from model complexity, heavy boards, wide dimensions, or slow upstream data refreshes.

## Common pressure points

- very large or heavily dimensioned models
- formulas with too much repeated logic
- boards with too many visuals or broad filters
- source data that refreshes slowly or inconsistently

## Improve performance by simplifying first

Before you add workarounds, check whether the model, board, or database can be made smaller, cleaner, or more focused.
