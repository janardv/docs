title: Data mismatches
description: Investigate data mismatches between sources, models, and views.
icon: database
---

A data mismatch happens when the source record set, database output, and model result no longer agree.

## Common causes

- the source system changed
- a refresh did not run when expected
- a mapping field changed meaning
- a board or view uses a different filter set than the source check

## Where to start

Check the database first. Confirm the incoming records, dates, and categories before you investigate the model formula.
