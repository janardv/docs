When a formula returns an unexpected value, start with structure before you assume the math is wrong.

## Common causes

- a referenced variable was renamed or moved
- the formula is using the wrong scenario or time context
- a dimensioned variable is being used without the expected breakdown
- a helper variable returns blank when the main formula expects a number
- the output is aggregating differently than you assumed

## A practical debugging order

1. Open the source variable.
2. Check the exact formula text.
3. Confirm referenced variables resolve correctly.
4. Review time and dimension context.
5. Compare the output in a simple view before checking a board.

## Prevent repeat issues

Most formula issues come from hidden complexity. Shorter formulas, stable naming, and helper variables reduce the chance of a repeated error.
