Functions help you express common logic without rewriting the same pattern each time. Oculon formulas usually combine standard math with planning-specific helpers.

## Common function categories

- **Math**: sum, round, absolute value, powers, and related numeric logic.
- **Logical**: conditional branches such as `IF`, `AND`, and `OR`.
- **Time**: functions that inspect month, quarter, year, or period relationships.
- **Financial**: functions for cash flow, return, and planning-style calculations.
- **Statistical**: averages, counts, rank, and spread measures.

## How to choose the right function

Use the simplest function that matches the business question. A short, obvious formula is easier to audit than a clever one that only one model builder understands.

## Read functions in context

A function that works at the aggregate level may behave differently when a variable is dimensioned or filtered by time. Always review the output in the exact context where the result will be used.
