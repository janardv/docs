The formula editor is where you write, review, and refine calculation logic in Oculon. It is designed to keep formulas readable while still supporting planning-specific logic.

## What to expect in the editor

In the editor, you can usually:

- type formulas directly on a variable
- use autocomplete for variables and functions
- review how references resolve
- adjust filters or context while you build

## A practical workflow

1. Select the variable you want to calculate.
2. Open the formula editor.
3. Type the expression or choose from suggestions.
4. Review the result in the grid.
5. Refine the logic until the output matches the business rule.

## Use the editor for review, not just creation

The editor is also the fastest place to audit a formula. If a number looks wrong in a board or view, open the source variable and review the editor before you troubleshoot downstream outputs.
