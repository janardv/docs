Most planning models reuse the same small set of formula patterns. Once you know these patterns, you can build faster and keep models easier to review.

## Common patterns

- **Driver-based growth**: calculate an output from one or more input drivers.
- **Actuals-to-forecast switch**: use actual values before the cutoff and planned logic after it.
- **Allocation**: distribute a total across dimension values based on a driver.
- **Run-rate extrapolation**: project a recent trend into future periods.
- **Variance logic**: compare actual, budget, and forecast values in a controlled way.

## Use patterns consistently

If your team uses the same approach for headcount planning, revenue build, and cost allocation across models, reviews get much easier. The formula does not need to look identical every time, but the intent should be recognizable.

## Document unusual logic

If a formula pattern is specific to one business process, add a short note or use a clearly named helper variable so the next editor can follow the reasoning.
