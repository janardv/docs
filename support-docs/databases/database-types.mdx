Teams usually work with two broad database patterns in Oculon.

## Manual databases

Use a manual database when you want to define and maintain the structure directly in Oculon. This works well for planning support tables, reference lists, or controlled internal records.

## Integration-backed databases

Use an integration-backed database when records should come from an external system such as a CRM, data warehouse, spreadsheet, or business app.

## How to choose

If Oculon is the system of workflow for the records, create the database manually. If another system owns the data, connect that system and refresh it into Oculon.
