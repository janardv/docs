Create a scenario when you want to test a new assumption, preserve a baseline, or review a draft without changing the main version.

## A practical workflow

1. Open the scenario selector.
2. Create a new scenario from the current baseline.
3. Give it a name that explains its purpose.
4. Make only the changes needed for that case.
5. Compare or merge once the review is complete.

## Naming guidance

Good scenario names usually include the purpose and status, such as `Hiring plan - draft` or `FY26 board case - locked`.

## Keep the list clean

Archive, lock, or retire scenarios that are no longer active. Too many unlabeled scenario drafts make review slower and increase the chance of editing the wrong one.
