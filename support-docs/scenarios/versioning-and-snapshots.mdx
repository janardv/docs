Versioning and snapshots help you preserve a planning state before the next round of changes begins.

## When to create a snapshot

Create a snapshot when you reach a milestone such as budget submission, executive review, or forecast sign-off.

## Why snapshots are useful

They give you a clean point of reference for comparison, audit, and discussion. Without snapshots, teams often argue about which version of the truth they are reviewing.

## Snapshot versus scenario

A scenario is for active what-if work. A snapshot is for preserving a state so you can return to it or compare against it later.
