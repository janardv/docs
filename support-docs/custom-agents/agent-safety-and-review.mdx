---
title: Agent safety and review
description: Use review and safety practices to keep agent behavior reliable and appropriate.
icon: shield
---

Custom agents should be reviewed like any other workflow automation that can influence planning decisions.

## Safety controls to use

- narrow instructions
- scoped permissions
- limited actions
- visible review points
- clear ownership for maintenance

## Review with real examples

Test the agent on prompts that reflect how the team will actually use it. Review both useful answers and edge cases where the model or data may be ambiguous.

## Update safety with capability

As an agent gains more context or actions, strengthen the review path as well. A more capable agent needs tighter governance, not looser governance.
