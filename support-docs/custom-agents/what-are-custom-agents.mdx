Custom agents let you package instructions, approved context, and allowed actions into a repeatable assistant inside Oculon. They are useful when the same analysis or workflow support is needed often.

## What a custom agent can help with

A custom agent can help summarize a board, explain a planning model, guide a user through a process, or assist with a repeatable review step.

## Why custom agents matter

Agents make specialized workflows easier to repeat. Instead of re-explaining the same rules each time, you define the scope once and reuse it.

## Keep the goal specific

The best custom agents solve one class of problem well. Broad, vague agents tend to produce inconsistent results.
