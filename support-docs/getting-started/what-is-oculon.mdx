Oculon is a planning and analysis workspace for teams that need one place to model, review, and share business decisions. You can use it to build driver-based models, connect source data, compare scenarios, and present results without moving work between disconnected spreadsheets.

![](/images/getting-started/fr-model-details.png)

## What you can do in Oculon

- Build models with variables, dimensions, time logic, and formulas.
- Bring in source data through databases and integrations.
- Test assumptions in separate scenarios before you publish changes.
- Share views and boards with the people who need the result, not the full model.

## How Oculon is different from a spreadsheet-only workflow

Oculon keeps structure, calculation logic, and permissions in one system. That means you can reuse the same variables across reports, keep actuals and forecast logic aligned, and let teammates work in the same model without passing files around.

## Where most teams start

1. Create or open a workspace.
2. Build a model with a clear date range.
3. Add variables and any dimensions you need.
4. Connect source data or create a database.
5. Review the result in views and boards.

## When to use Oculon

Use Oculon when you need repeatable planning, controlled collaboration, and a clear audit trail of what changed. It works best when the same model needs to support both day-to-day analysis and decision-ready reporting.
