---
title: Private vs shared views
description: Understand the difference between private and shared views in collaborative work.
icon: users
---

Private and shared views solve different problems.

## Private views

Use a private view when you need a personal working surface, an in-progress review filter, or a temporary way to inspect part of the model.

## Shared views

Use a shared view when several people need the same definition of the output. Shared views are especially useful for recurring reviews, monthly close, and team-specific reporting.

## A simple rule

If the view is part of a repeatable process, share it. If it is only for your current working session, keep it private until the pattern is stable.
