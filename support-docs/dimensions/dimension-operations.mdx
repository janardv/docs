Dimension operations are the actions you use to keep a dimension clean, accurate, and useful over time.

## Common operations

- create a new dimension
- add or rename values
- reorder or regroup values
- attach or remove a dimension from a variable
- review how formulas aggregate across the dimension

## Edit with caution

If a dimension is already used in models or boards, changing the structure can affect formulas, filters, and saved views. Make structural changes in a controlled way and review the downstream impact.

## Use operations to reduce clutter

Do not keep unused values, duplicate categories, or temporary naming in a production dimension. Clean dimensions make filtering and comparison much easier.
