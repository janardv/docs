Cloning and versioning help you preserve a known-good state before making larger changes.

## When to clone

Clone a model when you want a separate copy to explore a new structure, a major planning cycle, or a major business assumption without affecting the current one.

## When to version

Use versioning when you want to preserve history inside the same model lineage. Versions are especially useful around budget approval, forecast lock, and executive review milestones.

## A simple rule

Clone when the structure itself may diverge. Version when the structure stays mostly the same but the state needs to be recorded.
