A model is the main planning workspace in Oculon. It combines variables, formulas, time settings, dimensions, scenarios, and links to source data so you can build and review a business plan in one place.

## What a model contains

A typical model contains:

- input variables and assumptions
- calculated outputs
- a defined date range and time granularity
- optional dimensions for analysis
- scenario logic for what-if planning

## Why models matter

The model is where planning logic becomes reusable. If you build it well once, the same structure can support reporting, scenario review, and board-level communication.
