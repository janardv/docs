Linked models let you reuse logic and outputs across separate planning areas without duplicating the same work.

## When to link models

Link models when:

- one team owns a source plan that another team depends on
- shared drivers should stay centrally controlled
- you need a modular planning setup instead of one oversized model

## What good linking looks like

Keep ownership clear. The source model should own the metric. The receiving model should consume it, not redefine it in a slightly different way.

## Review dependencies regularly

A linked model setup is powerful, but it also creates dependencies. Review critical links after structural changes, major scenario work, or model version updates.
