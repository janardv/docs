---
title: Agent connections
description: Connect custom agents to the systems and sources they need to do useful work.
icon: plug
---

Connections determine which systems or resources an agent can use while helping a user.

## Connect only what the workflow needs

If an agent is meant to explain a board, it may only need access to the board and its source model. It usually does not need broad workspace-wide context.

## Check connection ownership

Every connection should have a business owner, an access model, and a review path. That is especially important when the connection reaches an external system.

## Test the failure path

Do not only test the happy path. Confirm what the agent does when a connected source is unavailable, outdated, or restricted.
