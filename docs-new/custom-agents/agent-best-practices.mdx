The best custom agents are specific, scoped, and easy to evaluate.

## Recommended practices

- build one agent for one repeatable job
- keep instructions short and explicit
- limit context to approved sources
- give the agent a clear owner
- review outputs before you scale usage

## Design for trust

People adopt agents faster when the boundaries are obvious. Be clear about what the agent knows, what it can do, and when a human should still make the final call.
