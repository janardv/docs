Start a custom agent with a narrow goal, a clear audience, and only the context it actually needs.

## A practical setup workflow

1. Define the job the agent should perform.
2. Add the business context it should understand.
3. Decide which data or resources it may use.
4. Limit the actions it can take.
5. Test the agent on realistic prompts before you share it.

## Name the agent after the workflow

Use names such as `Board reviewer`, `Forecast explainer`, or `Model QA helper`. A clear name helps people choose the right agent and set the right expectations.
