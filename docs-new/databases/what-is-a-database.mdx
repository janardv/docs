A database in Oculon stores structured records that can be reviewed directly or used as model inputs. It gives you a stable place to manage operational or imported data without rebuilding it inside each model.

## How databases support planning

Databases help you:

- centralize source records
- map fields into model logic
- refresh data from integrations
- keep reporting inputs consistent across teams

## Database versus model

Use a database for source records and row-level detail. Use a model for planning logic, calculations, scenarios, and business rules.
