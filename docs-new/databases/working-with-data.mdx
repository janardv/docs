Working with data in Oculon is usually a cycle of loading, reviewing, mapping, and refreshing.

## A practical workflow

1. Create or connect the database.
2. Confirm the incoming fields and records.
3. Review data quality before you link it to a model.
4. Map the fields you need for time, dimensions, or planning inputs.
5. Refresh and validate as the source changes.

## Keep data quality visible

A database is only useful if people trust it. Review null values, duplicates, date formats, and category spelling before you publish a board or rely on the data in planning logic.

## Separate raw and modeled logic

Use the database to store and clean the records. Use the model to decide how those records should affect planning outputs.
