You can create dimensions from the library or directly while building a model. Setting up dimensions correctly ensures your data stays organized and easy to analyze.

## Where to create a dimension

![](/images/getting-started/fr-dimension-list.png)

There are two primary ways to create a new dimension:

- **From the Library**: Navigate to the Library and open the **Dimension list** page to create and manage the dimension centrally.
- **From a Model**: While you are actively working in a model, you can open the page panel and select the option to add dimensions on the fly.

## Editing default values

Once a dimension is added, Oculon automatically creates default values to act as placeholders. For example, if you name your new dimension `Product`, initial values such as `product 1` and `product 2` are generated for you.

You can open the dimension to edit these placeholder rows into your actual business values and add as many additional rows as you need.

## The dimension details page

![](/images/getting-started/fr-dim-details.png)

From the dimension details page, you have full control over the structure of your dimension. Here you can:

- **Add rows**: Continue adding new values to the dimension list.
- **Add columns**: Add columns to define properties or relationships. This allows you to store additional context about the dimension members or use them to map dimensions to each other.
