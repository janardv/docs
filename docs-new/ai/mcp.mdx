Model Context Protocol, or MCP, is a way to connect AI systems to tools and data in a structured, permission-aware way. In an Oculon context, MCP can help AI experiences reach beyond one page or one answer and work with approved systems more directly.

## Why MCP matters

MCP is useful when AI needs access to trusted tools or structured context instead of only free-form text. It creates a cleaner bridge between the assistant and the systems the business actually uses.

## How to think about it in Oculon

If built-in AI helps inside the product, MCP extends what that AI can safely understand or act on through controlled connections.

## Keep governance first

Any MCP setup should be scoped, reviewed, and permission-aware. More tool access is not automatically better. The right MCP setup is the smallest one that supports the workflow well.
