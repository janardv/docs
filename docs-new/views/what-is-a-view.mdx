A view is a saved, filtered way to look at a model. It lets you show only the variables, dimensions, scenarios, time periods, or visual elements that matter for a specific audience or workflow.

![](/images/getting-started/fr-views.png)

## Why views matter

Views help you avoid forcing every user to navigate the full model. A model builder can keep the complete logic, while collaborators work from a focused slice of that same model.

## Common uses for views

- recurring management review packs
- department-specific planning surfaces
- clean review pages for approvals
- filtered working sets for model builders
