A view is a saved way to look at a model or database in Oculon. It narrows the source to the content that matters for one workflow, audience, or decision.

![Views panel in Oculon](/images/getting-started/fr-views.png)

## Why views matter

Views let you reuse the same source in different ways. You can keep one model or database as the source of truth and create focused review surfaces without rebuilding the underlying logic or records.

## A view stays connected to its source

A view is not a disconnected copy. If the source model or database changes, the view reflects the current state through the filters, grouping, and display rules you saved.

## Where views fit

Use a view when you want to:

- narrow a model to the right variables, dimensions, scenarios, or time periods
- narrow a database to the right records or fields
- embed a saved model or database slice on a board
