A view is not a disconnected copy of a model. It reflects the current state of the source model through the filters and rules you saved.

## What changes a view

A view can change when:

- source variables or sections are updated
- scenarios or time settings change
- permissions change for the viewer
- charts or filters referenced by the view are modified

## Why this matters

Because views stay connected to the source, they are powerful for collaboration. They also need clear ownership so people know who should update them when the underlying model evolves.
