Scenario Compare works similarly to Time Compare but allows you to compare different scenarios (versions of your data) rather than different time periods. You can compare your default scenario against one or more alternative scenarios.

## Overview

You can compare the default scenario with one or more scenarios. This helps in:
- Performing "What-if" analysis.
- Comparing Forecast vs. Budget.
- Evaluating the impact of different strategic decisions.

## Comparing in Models

In models, scenario comparison creates additional columns similar to Time Compare:
- Each scenario is displayed in its own column or group of columns.
- You can view variances between scenarios to understand the impact of different assumptions.

## Comparing on Board Charts

Board charts for scenario comparison work exactly like Time Compare:
- Data is visualized using bars or lines.
- You can compare the same metric across multiple scenarios in a single chart.
