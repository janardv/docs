Permission inheritance means access can flow from a parent container to the content inside it.

## Why inheritance matters

Inheritance keeps permission management simple. Instead of managing each item separately, you can control access at the folder, teamspace, or shared structure level.

## Where to be careful

Inheritance is helpful until someone assumes a child item is private when it still inherits a broader rule. When you work with sensitive data, verify effective access instead of assuming it.

## Review effective permissions

Whenever a model or board is moved, shared broadly, or placed in a new teamspace, check whether inherited permissions changed.
