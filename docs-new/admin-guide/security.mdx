Security in Oculon includes access control, authentication, visibility management, and activity review.

![](/images/getting-started/fr-workspace-set.png)

## Security areas to review

- workspace and resource permissions
- authentication method and strength
- sharing rules for sensitive content
- audit and review processes

## Build for least privilege

Give people the smallest access scope that still lets them do their job. Least privilege is easier to review and safer to maintain.

## Revisit security after change

Security assumptions should be reviewed after major org changes, workspace reorganizations, or new integrations.
