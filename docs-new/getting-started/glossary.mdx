Use this glossary when you need a quick definition of a product term that appears elsewhere in the docs.

## Core terms

**Variable**: A named line in a model that stores values, formulas, or both.

**Helper variable**: A supporting variable that simplifies a longer calculation.

**Dimension**: A category used to break a variable into more detailed parts.

**Dimension value**: An item inside a dimension, such as `North America` inside `Region`.

**Model**: The planning surface where variables, formulas, time logic, and dimensions come together.

**Database**: A structured table of records used for source data, analysis, or model inputs.

**Integration**: A connection to an external system that brings data into Oculon.

**Query**: The rule set used to fetch and shape data from an integration.

## Planning terms

**Scenario**: A branch of a model used to test assumptions without changing the main version.

**Override**: A scenario-specific value that differs from the inherited baseline.

**Last actual date**: The most recent period treated as actual data in a model.

**Relative time**: A dynamic time reference such as `this month`, `last quarter`, or `month 1`.

**Granularity**: The level of time detail used in the model, such as monthly or quarterly.

**Time rollup**: The way Oculon groups lower-level periods into higher-level periods, such as months into quarters.

**Time aggregation**: The business rule that determines what a metric should mean when it is shown at quarter or year level.

## Reporting terms

**View**: A saved filter over model content.

**Board**: A collection of charts, tables, and summary blocks used to present results.

**KPI block**: A summary tile that highlights one metric and its current value.

**Compare**: A side-by-side difference between scenarios, versions, or time selections.

## Access terms

**Workspace**: The top-level environment that holds people, settings, and content.

**Group**: A set of users managed together for access control.

**Role**: A permission level that controls what a user can do.
