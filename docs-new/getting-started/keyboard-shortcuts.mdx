Keyboard shortcuts help you move through Oculon without switching back to the mouse for every action.

## Key notation

- `Cmd` means Command on Mac.
- `Ctrl` means Control on Windows.
- `Shift` means Shift.
- `Enter` means Return or Enter.
- `Esc` means Escape.

## Global shortcuts

- `Cmd/Ctrl + K`: open command palette or global search.
- `Cmd/Ctrl + P`: quick open recent or favorite items.
- `Cmd/Ctrl + /`: open the shortcuts panel.
- `Cmd/Ctrl + F`: search in the current page or table.
- `Cmd/Ctrl + [` and `Cmd/Ctrl + ]`: move back and forward.

## Grid shortcuts

- `Enter`: edit the selected cell.
- `Esc`: cancel the current edit.
- `Tab` and `Shift + Tab`: move between cells.
- `Cmd/Ctrl + C`, `X`, `V`: copy, cut, and paste.
- `Cmd/Ctrl + Shift + V`: paste values only.
- `Cmd/Ctrl + Z`: undo.
- `Cmd/Ctrl + Shift + Z`: redo.
- `Delete` or `Backspace`: clear the selected value.

## Model shortcuts

- `Cmd/Ctrl + Shift + L`: toggle filters.
- `Cmd/Ctrl + Shift + F`: open the filter builder.
- `F9`: recalculate the selection.
- `Cmd/Ctrl + Shift + \\``: show formulas.

## Dashboard and agent shortcuts

- `V`: toggle board builder mode.
- `Cmd/Ctrl + Shift + A`: open the agent console.

Keep the shortcuts that matter most to your workflow nearby. Most teams get the biggest speed gain from search, cell editing, filtering, and undo/redo.
