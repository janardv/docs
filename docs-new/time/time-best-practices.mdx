A clean time setup makes every other part of the model more reliable.

## Recommended practices

- Set the model date range before you write complex formulas.
- Use one primary granularity for the model and keep it consistent.
- Update the last actual date as part of the close process.
- Use relative time for reusable logic instead of hard-coded month references.
- Review how key metrics aggregate to quarter and year.

## Keep governance simple

Document the time assumptions that matter most, especially fiscal year rules and the forecast cutoff. Teams move faster when those defaults are obvious.
