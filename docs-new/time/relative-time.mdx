Relative time lets you define logic without hard-coding a fixed month or quarter. That makes models and reports easier to reuse as time moves forward.

## Common relative time patterns

- this month
- previous month
- next quarter
- last 12 months
- month 1, month 2, and similar rolling references

## Where relative time helps

Use relative time in formulas, views, and board filters when the same logic should keep working after each month-end close.

## Keep it understandable

Relative time is powerful, but it can confuse readers if the rule is hidden. Name related variables clearly and explain the time logic in shared models when it is business-critical.
