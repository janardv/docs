Many errors are easier to resolve once you identify which layer is failing: source data, model logic, sharing, or workspace access.

## A simple triage order

1. Confirm the user is in the right workspace, scenario, and time context.
2. Check whether the source model or database is correct.
3. Review permissions and sharing rules.
4. Look for recent structural changes or refresh failures.

## Record what fixed it

When a recurring error is resolved, document the cause and the fix. That turns one support case into a reusable troubleshooting pattern.
