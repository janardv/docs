Agent issues usually show up as weak answers, missing context, blocked actions, or behavior that no longer matches the intended workflow.

## Common causes

- the agent has stale instructions
- the context is too broad or too narrow
- permissions or connections changed
- the task is not specific enough for the current setup

## What to review

Start with the prompt, then check the agent context, scope, and allowed actions. Most agent problems become clear once you inspect those three layers together.
