---

Formula issues usually show up as wrong numbers, blanks where a value should exist, or logic that changes unexpectedly across time or dimensions.

## Check these first

- the exact formula text
- referenced variables and helper lines
- time and scenario context
- dimension assumptions
- aggregation at summary levels

## Fastest resolution path

Start at the source variable, not the board. If the source line is correct, move outward to the view or board. If the source line is wrong, keep the debugging inside the model until the output is stable.
