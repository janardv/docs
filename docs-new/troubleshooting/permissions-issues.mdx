title: Permissions issues
description: Troubleshoot access problems caused by sharing rules, roles, or inheritance.
icon: shield
---

Permission issues usually appear as missing content, edit restrictions, or unexpected visibility.

## Common causes

- a user has the wrong role
- group membership is outdated
- inherited permissions changed after content moved
- the item was shared more narrowly than expected

## How to resolve

Check the effective access path from workspace role to group membership to item-level permission. The problem is usually in one of those three layers.
