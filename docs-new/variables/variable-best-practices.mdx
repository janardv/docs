Well-managed variables make the rest of the model easier to build and easier to trust.

## Recommended practices

- Use business names that other people already understand.
- Separate inputs, calculations, and outputs into different sections.
- Choose one formatting standard for similar metrics.
- Add dimensions only when they improve analysis.
- Prefer short formulas that call helper variables over one long formula.

## Review before you scale

Before a model grows, check whether variable names, section layout, and references still make sense. A small cleanup early is much easier than a large restructure later.

## Protect shared logic

If a variable feeds many reports or linked models, treat it as shared infrastructure. Changes should be reviewed with the people who depend on it.
