A variable is the basic building block of a model in Oculon. It represents a metric, driver, assumption, or calculated line that you want to track over time.

![](/images/getting-started/fr-variable.png)

## What a variable can hold

A variable can hold:

- entered values
- calculated results from a formula
- values broken down by one or more dimensions
- formatting rules such as currency or percentage display

## Where variables are used

You use variables everywhere in model building. They feed formulas, power views and boards, and often connect to data from databases or linked models.

## Why variables matter

Variables give your model structure. If you name and organize them well, you make formulas easier to read, reports easier to trust, and changes easier to review.

## A simple example

A revenue model might include variables such as `Price`, `Volume`, `Discount`, and `Net revenue`. Some of those values are entered directly. Others are calculated from the rest.
