Board layout controls how quickly someone can understand the message on the page.

## Adding Content to the Canvas

![](/images/getting-started/fr-board-add-card.png)

The board canvas is a dynamic space where you can combine data visualizations with descriptive text to build impactful reports.

To add a new element (called a **Card**), click the `+` icon that appears when you hover over the canvas. This opens a menu of available items:

| Item Type | Description |
| :--- | :--- |
| **Text / Heading** | Add formatted text or headers to provide context and structure. |
| **Table** | Insert a blank table to manually enter or organize data. |
| **Ordered / Unordered List** | Create bulleted or numbered lists for sequential steps or key points. |
| **Checklist** | Add interactive checkboxes to track tasks or requirements. |
| **Chart** | Embed visualizations, including **Bar** and **Line charts**, powered by your models. |

> **Note**: You can type text directly anywhere on the canvas at any time; there is no need to select it from the `+` menu unless you want specific formatting.

## Layout & Arrangement

Oculon provides a flexible grid system to help you align your analysis and reporting elements.

- **Side-by-Side Cards**: You can arrange up to two cards (such as charts or KPI blocks) side-by-side to compare metrics or show related data at a glance.
- **Block Management**: Every element on the canvas is treated as a block. To manage a block:
    1. Hover over the element to reveal the **six dots icon** (handle) on the left side.
    2. Click and drag the handle to **move** the block to a new position.
    3. Click the handle once to open a menu for **copying**, **duplicating**, or **deleting** the block.

- **Drag and Drop**: You can drag any block and place it exactly where you want on the canvas. 
- **Resizing**: Shift cards between full-width and half-width by dragging them into position side-by-side.

## Start with information hierarchy

Put headline KPIs and the core question at the top. Follow with the supporting charts and detail tables. Keep secondary analysis lower on the page.

## Group related content

A board should read in sections, not as a wall of visuals. Keep related metrics, filters, and explanations together so the viewer does not have to reconstruct the story.

## Design for scanning

Use enough spacing, clear labels, and a consistent reading order. If a board only makes sense after a long explanation, the layout needs more structure.
