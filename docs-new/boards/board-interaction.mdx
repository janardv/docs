A board is most useful when the viewer can explore the data without losing the main story.

## Common interactions

- changing a filter or scenario
- adjusting the time range
- opening an embedded or linked view for deeper detail
- switching between related visual states

## Keep interactions predictable

Interactive controls should change the board in ways the viewer expects. If one filter changes only part of the page while another changes everything, label that difference clearly.

## Design for both readers and explorers

Some people only want the headline. Others want to investigate. A good board works for both.

If the board relies on embedded views, keep those view definitions stable and review them after source changes.
