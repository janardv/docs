Good scenario hygiene keeps experimentation fast and review trustworthy.

## Recommended practices

- Keep scenario names explicit and consistent.
- Create scenarios for decisions, not for every minor edit.
- Lock or archive approved scenarios.
- Review overrides before you merge.
- Compare focused cases instead of broad, mixed drafts.

## Treat scenarios as communication tools

A strong scenario is easy for another person to explain. If nobody can summarize the point of the scenario in one sentence, it probably needs cleanup.
