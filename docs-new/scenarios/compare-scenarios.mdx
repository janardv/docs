Scenario comparison helps you answer one question clearly: what changed, and how much does it matter?

## What to compare

Teams usually compare:

- current forecast versus approved budget
- draft case versus main scenario
- optimistic case versus downside case
- one department assumption versus another

## How to compare well

Start with the few metrics that drive the decision. Then check the key dimensions, time periods, and outputs that explain the variance.

## Avoid noisy comparisons

If you compare too many changes at once, the result is hard to interpret. Keep scenarios focused so the difference tells a clear story.
