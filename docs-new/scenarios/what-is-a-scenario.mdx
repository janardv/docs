A scenario is a named branch of a model that lets you test changes without replacing the current baseline. You can use scenarios to explore alternatives, review proposed changes, and compare outcomes side by side.

![](/images/getting-started/fr-scenario.png)

## Why scenarios matter

Scenarios help you protect the main plan while still moving quickly. Teams can model upside, downside, or department-specific assumptions without forcing everyone onto the same draft.

## Common scenario use cases

- budget versus latest forecast
- hiring freeze or expansion cases
- pricing or volume sensitivity analysis
- board-approved baseline versus working draft

## What a scenario is not

A scenario is not a separate model copy for every idea. Use it when the same model structure should support multiple outcomes.
