Helper variables and modifiers let you turn complex logic into smaller, readable steps.

## Helper variables

A helper variable is an intermediate line that supports a larger calculation. Use one when the same logic appears more than once or when the main formula is becoming too long to review safely.

## Modifiers and context helpers

Built-in keywords you can use in formulas for time, fiscal periods, cohorts, and model context. They help you avoid hand-rolling common values like month index, quarter, or time step.

### Cohort

| Keyword | Description |
| --- | --- |
| `cohort` | Creates a cohort dimension for cohort-based modeling and analysis. |

### Time and calendar

| Keyword | Description |
| --- | --- |
| `month` | Returns the month index (`Jan = 1`, `Feb = 2`, and so on). Useful for seasonality or month-based logic. |
| `quarter` | Returns the quarter (`1-4`). Helps apply logic specific to quarters. |
| `year` | Returns the calendar year of the current time step. |
| `daysinmonth` | Returns the total number of days in the current month. |
| `today` | Returns the current time step index based on today's date. |

### Fiscal

| Keyword | Description |
| --- | --- |
| `fiscalmonth` | Returns the fiscal month (`1-12`), based on your fiscal year settings. |
| `fiscalyear` | Returns the fiscal year of the current time step (requires fiscal year to be enabled). |

### Time index and model scope

| Keyword | Description |
| --- | --- |
| `timestep` | Returns the index of the current time step (for example, `0`, `1`, `2`). |
| `date` | Alias of `timestep`; also returns the current time step index. |
| `numtimesteps` | Returns the total number of time steps in the model. |

### Model logic

| Keyword | Description |
| --- | --- |
| `lastActualDate` | Returns the index of the [Last actual date](/docs-new/time/last-actual-date) set in model settings. Useful for separating actuals versus planned logic. |
| `blank` | Represents an empty value. Commonly used in conditional formulas. |

## Why this matters

Breaking logic into smaller parts makes reviews faster. It also reduces the risk that one formula change creates several hidden side effects elsewhere in the model.

These helpers are especially useful when you build [Relative time](/docs-new/time/relative-time) logic or formulas that react to the [Last actual date](/docs-new/time/last-actual-date).

## A good pattern

Instead of one long formula that handles seasonality, actuals, and overrides at once, create one helper for each concern and let the final variable reference those helpers.
