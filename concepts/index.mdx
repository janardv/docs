## Availability notes

Some published Concepts pages describe features that are not on by default in every environment—including [Projects](/concepts/workspace-and-collaboration/projects-and-tasks), [Feed](/concepts/ai-and-agents/feed), Publishing, Exports, and board code blocks. Those pages include availability notes. Do not treat them as generally available everywhere.
