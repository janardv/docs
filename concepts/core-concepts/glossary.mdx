Short definitions of the terms you see in Oculon. Each section links to the page that explains the concept in depth.

## Workspace and organization

**Workspace**: Your company's environment in Oculon. It holds members, settings, shared dimensions, integrations, scenarios, and all spaces. See [Workspaces](/concepts/workspace-and-collaboration/workspaces).

**Spaces**: The sidebar section that lists your Private Space and the teamspaces you belong to. Spaces hold models, Transactions, boards, and folders.

**Teamspace**: A shared space for a team. A teamspace is **Open** (anyone in the workspace can join) or **Closed** (people request to join). See [Teamspaces and private space](/concepts/workspace-and-collaboration/teamspaces-and-private-space).

**Private Space**: Your personal space. Only you can see its contents unless you share an item.

**Folder**: A container inside a space for grouping related files.

**Library**: An index of every model, Transactions, board, dimension, and integration you can access across the workspace. You also manage dimensions and integrations from the Library.

**Shared with me**: A list of the items other people have shared with you directly.

## Data and structure

**Transactions**: Source records, such as ledger entries, invoices, or deals, that come from an integration, an uploaded file, or manual entry. See [Transactions](/concepts/data-and-structure/transactions).

**Database**: The former name for Transactions. You may still see it in older content.

**Integration**: A connection to an external system, such as Xero or QuickBooks, that brings records into Transactions. Integrations are separate from AI connectors.

**Dimension**: A shared category, such as `Region` or `Product`, used to break variables down. Dimensions belong to the workspace, so any model can use them. See [Dimensions](/concepts/data-and-structure/dimensions).

**Dimension value**: One item in a dimension, such as `EMEA` in `Region`.

**Variable**: One line in a model that holds input values, a formula, or both. See [Variables](/concepts/data-and-structure/variables).

## Modeling

**Model**: The planning surface where variables, formulas, time settings, and linked data come together. See [Models](/concepts/modeling/models).

**Linked model**: Another model that the current model references, so values flow from one model to the other.

**Formula**: The calculation that produces a variable's values. See [Formulas](/concepts/modeling/formulas).

**Actual formula**: The formula a variable uses for periods up to and including the Last actual date.

**Planned formula**: The formula a variable uses for periods after the Last actual date. The formula editor labels this tab **Plan**.

**Helper variable**: A supporting variable that breaks a long calculation into readable steps.

**Scenario**: A branch of planning data that inherits values until you override them. See [Scenarios](/concepts/modeling/scenarios).

**Default Scenario**: The baseline scenario every workspace starts with. It can't be deleted.

**Override**: A value you enter in place of the calculated or inherited one. In a scenario, an override differs from the value it would inherit from the baseline. In a model or Transactions cell, an override replaces the formula result for that cell until you choose **Revert to original**.

## Time

**Granularity**: The time detail a model uses: `monthly`, `quarterly`, or `yearly`. See [Time granularity](/concepts/data-and-structure/time/time-granularity).

**Date range**: The first and last period a model covers.

**Last actual date**: The model setting that separates actual periods from planned periods. See [Last actual date](/concepts/data-and-structure/time/last-actual-date).

**Relative time**: A time reference that moves with each period, such as `This month`, `Previous month`, or `Last 3 months`. See [Relative time](/concepts/data-and-structure/time/relative-time).

**Time rollup**: How lower-level periods group into higher-level ones, such as months into quarters. You choose rollups in a view with **Roll up**. See [Time rollups](/concepts/data-and-structure/time/time-aggregation#time-rollups).

**Time aggregation**: What value represents a grouped period, set per variable as **Sum**, **Average**, **Initial**, or **Final**. See [Time aggregation](/concepts/data-and-structure/time/time-aggregation).

## Analysis and reporting

**View**: A saved way of looking at a model or Transactions. Model views store the date range, filters, sorting, rollups, and comparison settings. Transactions views store filters, sorting, and grouping. See [Views](/concepts/analysis-and-reporting/views).

**Compare**: A view setting that shows scenarios or time periods side by side, with value, variance, and variance %. See [Compare](/concepts/analysis-and-reporting/compare).

**Board**: A reporting page that combines charts, tables, and KPI blocks. See [Boards](/concepts/analysis-and-reporting/boards).

**KPI block**: A board block that highlights one headline metric.

## Access and sharing

**Workspace Owner**: The workspace role that can manage members, settings, and billing.

**Member**: The standard workspace role for people who build and use content.

**Guest**: A person with limited access to specific shared items, such as an external reviewer, without full member access.

**Group**: A set of people you manage together for access.

**Viewer / Editor / Full Access**: Access levels for a single item. Viewers can read. Editors can change content. Full Access adds sharing and permission control. See [Sharing and permissions](/concepts/workspace-and-collaboration/sharing-and-permissions).

## AI and work

**AI assistant**: The chat you can open from any page to ask questions or build and change content. See [AI assistant](/concepts/ai-and-agents/ai-assistant).

**Custom agent**: An assistant with its own instructions, context, and allowed actions. Custom agents are listed on the sidebar **Team** tab. See [Custom agents](/concepts/ai-and-agents/custom-agents).

**Projects**: Task and project tracking, available when enabled for your workspace. See [Projects and tasks](/concepts/workspace-and-collaboration/projects-and-tasks).

**Feeds**: A stream of agent updates and approval requests, available when enabled for your workspace. See [Feed](/concepts/ai-and-agents/feed).
