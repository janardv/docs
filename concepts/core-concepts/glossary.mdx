Use this glossary when you need a quick definition of a product term that appears elsewhere in the docs.

## Core terms

**Variable**: A named line in a model that stores values, formulas, or both.

**Helper variable**: A supporting variable that simplifies a longer calculation.

**Dimension**: A category used to break a variable into more detailed parts.

**Dimension value**: An item inside a dimension, such as `North America` inside `Region`.

**Model**: The planning surface where variables, formulas, time logic, and dimensions come together.

**Transactions**: Structured tables of records used for source data, analysis, or model inputs. Older docs and some routes still say **Databases**; the public product term is Transactions.

**Database**: Legacy alias for Transactions. Prefer Transactions in current docs.

**Integration**: A connection to an external system that brings data into Oculon (Library Integrations), distinct from AI [Connectors & MCP](/concepts/ai-and-agents/context-and-connections).

**Library**: The hub for shared resources such as models, Transactions, dimensions, and boards.

## Planning terms

**Scenario**: A branch of a model used to test assumptions without changing the shared baseline.

**Default Scenario**: The product default baseline scenario (older docs sometimes said Main Scenario).

**Override**: A scenario-specific value that differs from the inherited baseline.

**Last actual date**: The model cutoff where actual behavior ends and planned behavior begins.

**Actual formula**: Formula logic used on the actuals side of the Last actual date.

**Planned formula**: Formula logic used on the planned side of the Last actual date.

**Relative time**: A dynamic time reference such as `this month`, `last quarter`, or `month 1`.

**Granularity**: The level of time detail used in the model, such as monthly, quarterly, or yearly.

**Time rollup**: How lower-level periods are grouped into higher-level periods, such as months into quarters.

**Time aggregation**: The business rule that determines what a metric should mean when shown at quarter or year level.

## Reporting terms

**View**: A saved way to look at model or Transactions content.

**Board**: A collection of charts, tables, and summary blocks used to present results.

**KPI block**: A summary tile that highlights one metric and its current value.

**Compare**: A side-by-side difference between scenarios or time selections.

## Organization and access terms

**Workspace**: The top-level environment that holds people, settings, and content.

**Spaces**: Sidebar umbrella for shared teamspaces and Private Space.

**Teamspace**: A shared Space for team content.

**Private Space**: A personal Space that is not shared with others.

**Group**: A set of users managed together for access control.

**Role**: A workspace or admin permission level that controls what a user can do.

**View / Edit / Full Access**: Common item-level share permissions on a specific resource.

## AI and work terms

**AI assistant**: Built-in chat help for modeling, reporting, and day-to-day questions.

**Workspace AI**: Admin settings for workspace AI defaults, agents, approvals, and tools.

**Custom agent**: A packaged assistant with scoped instructions, context, and allowed actions.

**Projects**: Work management for tasks and project activity when the feature is enabled in your environment.

**Feed**: Sidebar activity surface for AI and agent updates when enabled in your environment.
