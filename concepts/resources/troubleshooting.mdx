Use this hub when something looks wrong. Start with the triage checklist, then open the product-area section that matches the symptom. Prefer Concepts links for how the product works; keep deep operational runbooks for How-to Guides later.

## Triage checklist

1. Confirm you are in the right **workspace**, **Space**, **scenario**, and **time** context.
2. Confirm you can see and open the source object (model, Transactions set, view, or board).
3. Check **permissions** and sharing before assuming a product bug.
4. Check whether the issue is **data**, **formula**, **view/filter**, or **presentation**.
5. Note what changed recently (formula, share, join rule, connection, or refresh).

## Models and calculations

| Symptom | What to check | Concepts |
| :--- | :--- | :--- |
| Wrong or blank values | Formula text, referenced variables, time and scenario context | [Formulas](/concepts/modeling/formulas), [Variables](/concepts/data-and-structure/variables) |
| Totals disagree with detail | Aggregation, dimensions, and rollups | [Dimensions](/concepts/data-and-structure/dimensions), [Time](/concepts/data-and-structure/time) |
| Actuals vs plan look off | Last actual date and planned/actual formulas | [Last actual date](/concepts/data-and-structure/time/last-actual-date) |
| Unexpected scenario result | Active scenario, overrides, sync, merge direction | [Scenarios](/concepts/modeling/scenarios) |

Debug at the model line first. If the source variable is wrong, fix it before chasing board or view formatting.

## Performance

Large models, wide dimensions, heavy boards, and slow upstream refreshes are common pressure points. Simplify the model or board before adding workarounds. See [Models](/concepts/modeling/models) and [Boards](/concepts/analysis-and-reporting/boards).

## When to escalate

If triage still fails, capture:

- Workspace and object names
- Scenario and time context
- Whether others with the same access see the issue
- Recent formula, share, or connection changes

Do not use Concepts for internal debugging, feature-flag admin, or implementation traces.
