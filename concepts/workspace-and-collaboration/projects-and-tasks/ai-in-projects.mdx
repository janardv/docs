Projects can carry AI context that stays with the work. Use these controls when Projects is enabled for your workspace.

## Project instructions

On the project Overview, add **project instructions** so AI knows how to work on that project. Empty state copy invites you to **Add project instructions**.

Keep instructions short and specific to the project’s workflow.

## Project memory

Projects can store shared **memory** for agents working in that project. Pinned memories are always offered to the agents.

This is project-scoped. It is not the same as personal memories under My Account. See [Knowledge and memory](/concepts/ai-and-agents/knowledge-and-memory).

## Chats and files

- **Chats** on a project stay scoped to that project.
- **Files** on Overview and on tasks attach supporting resources to the work.

## Agent tasks

Overview can show **Agent tasks**. You can also assign an agent as a task assignee and run agent work from the task. Keep agent use aligned with [Custom agents](/concepts/ai-and-agents/custom-agents) and workspace AI policy.

## What this page does not claim

- Automatic memory of every chat turn
- That every workspace has agents or the same agent tools
- That Project AI replaces Workspace AI policy
