Projects can carry AI context that stays with the work. Use these controls when Projects is enabled for your workspace.

## Project instructions

On the project Overview, add project instructions so AI knows how to work on that project. If none exist yet, select **Add project instructions**.

Keep instructions short and specific to the project's workflow.

## Project memory

Projects can store shared memory for agents working in that project. Pinned memories are always offered to the agents.

Project memory is scoped to the project. It isn't the same as personal memories under My Account. See [Knowledge and memory](/concepts/ai-and-agents/knowledge-and-memory).

## Chats and files

Chats on a project stay scoped to that project. Files on Overview and on [tasks](/concepts/workspace-and-collaboration/projects-and-tasks/tasks) attach supporting resources to the work.

## Agent tasks

Overview can show Agent tasks. You can also assign an agent as a task assignee and run agent work from the task. Keep agent use aligned with [Custom agents](/concepts/ai-and-agents/custom-agents) and workspace AI policy.

## How project AI fits with other AI settings

Project instructions and memory apply only to AI working in that project. [Workspace AI](/concepts/ai-and-agents/workspace-ai) instructions still apply across the whole workspace, and your [personal memories](/concepts/ai-and-agents/knowledge-and-memory) still apply to your own chats.
