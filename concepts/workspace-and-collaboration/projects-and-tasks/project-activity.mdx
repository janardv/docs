**Activity** is the project-scoped event history for a project. Open it from the project detail **Activity** tab when Projects is enabled.

## What Activity shows

Activity lists recent project and task events, such as creates, edits, comments, and attachments. Each entry shows an actor and relative time.

Filters commonly include:

- **All activity**
- **Project**
- **Tasks**
- **Comments**

Use Activity to answer “what changed on this project?” without leaving the project.

## Separate from Model History

| Surface | Scope |
| :--- | :--- |
| **Project Activity** | Project and task collaboration events |
| [**Model History**](/concepts/modeling/models/model-history) | Model checkpoints, preview, and restore |

Do not treat Activity as a global History product. There is no shared History parent across Projects and models.
