Create and manage projects from the **Projects** portfolio when the feature is enabled. See [Projects and tasks](/concepts/workspace-and-collaboration/projects-and-tasks) for availability.

## Create a project

1. Open **Projects** in the sidebar.
2. Click **New project**.
3. Set the basics: name, summary, icon, members, status, dates, priority, and optional Space placement.
4. Optionally start from a template when templates are available in your workspace.
5. Save the project.

Keep the first version narrow. Add tasks and AI context after the project exists.

## Organize the catalog

From the Projects catalog you can:

- Search and filter projects (including **Shared with me** and **Archived**)
- Update status and lead
- Rename or change the icon
- Duplicate a project
- Complete, archive, restore, or delete when you have the required access
- Copy a project link

Pinning a project for quick access in Chats is a personal convenience in the client. Do not treat it as workspace-wide favorites.

## Place a project in a Space

You can associate a project with a Space so it appears under **Projects in this space**. That helps navigation. Access still comes from project sharing. See [Project settings and access](/concepts/workspace-and-collaboration/projects-and-tasks/project-settings-and-access).

## Lifecycle

| Action | Typical use |
| :--- | :--- |
| **Complete** | Mark the project finished |
| **Archive** / **Restore** | Hide or bring back inactive projects |
| **Duplicate** | Copy structure and tasks into a new project |
| **Delete** | Remove a project you no longer need (requires sufficient access) |

Archived project tasks are read-only.
