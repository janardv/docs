Some workspaces can insert a **Code block (AI)** from the board slash / insert menu. Choosing it opens AI chat to build the block at that spot rather than inserting a blank node.

## Availability

This option appears only when artifacts / code-block features are enabled for the workspace. If you do not see **Code block (AI)** in the insert menu, the feature is not available in your environment.

## When to use it

Use a code block when the board needs a custom interactive element that standard chart, table, or embed cards do not cover, and your workspace supports AI-built board code blocks.

Keep depth minimal until your workspace confirms the feature is generally available for your audience.
