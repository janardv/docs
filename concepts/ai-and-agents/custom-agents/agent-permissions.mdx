Custom agents run without anyone watching. Three things keep them safe: who can use the agent, what the agent itself can access, and which changes wait for a person's approval.

## Share an agent

Open the agent, select **Share**, add people or groups, and choose an access level.

| Access level | What a person can do |
| :--- | :--- |
| Can view and interact | See the agent and its results, chat with it, and act on its feed cards |
| Can edit | Also change its instructions, routines, files, and memory, and run routines manually |
| Full access | Also share the agent, change permissions, and delete it |

Whoever creates an agent gets Full access. Admins can limit who creates, shares, and uses agents in [Workspace AI](/concepts/ai-and-agents/workspace-ai).

## What the agent can access

An agent works with its own access, never the access of the person who created it or ran it. It can only use the resources someone has shared with it, and you need Full access to a resource to share it. Sharing something with an agent never gives a person access to it.

Share only what the routines need, and give view access unless the agent must change something. A routine set to Read only can't make changes, even if the agent has edit access.

## Approvals

Each routine has an approval rule. With Request review, the run pauses before it makes a change until someone approves it. With Proceed automatically, the agent makes changes without waiting.

Use Request review for any routine that changes models or Transactions. Keep Proceed automatically for routines that only read and report.

People with Can edit access can approve changes. If the routine allows it, people with Can view and interact can approve from Feed too.

When a run needs approval, it shows as Pending approval in [Feed](/concepts/ai-and-agents/feed) and Needs approval in the agent's [Activity](/concepts/ai-and-agents/custom-agents/agent-activity-and-runs). Open it, review what the agent wants to do, and select **Approve** or **Reject**. You can add a note to explain your decision. The run then picks up where it left off.

To hear about approvals right away, turn on **Agent needs your input** under **My Account → Notifications → AI & Agents**.

## Before you turn a routine on

Make sure the instructions are narrow, the agent can reach only what it needs, changes go through Request review, and you've tested the routine with Run now. Every agent should also have a named owner who keeps it up to date.

As an agent gets more routines or more access, tighten its review path to match.
