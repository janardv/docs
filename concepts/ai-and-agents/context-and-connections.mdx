Connections let AI work across Oculon and the other tools your team uses. They work in two directions, and both use Model Context Protocol (MCP), an open standard for connecting AI to tools and data.

The first direction brings outside tools into Oculon. With a plugin, Oculon AI can use tools from services such as Notion, or from any MCP server. You set these up under **Settings → My Account → Connectors & Plugins**.

The second direction brings Oculon into outside AI tools. Tools such as Claude, ChatGPT, or Cursor can work with your Oculon workspace. You set this up in your AI tool's MCP settings, using the Oculon MCP server URL.

## Connections vs Integrations

Plugins and connectors give AI live access to tools in other services. The AI assistant and custom agents use them, and you manage them under **Settings → Connectors & Plugins**.

Integrations do a different job. They import and sync source data into Oculon for use in Transactions and models. You manage them under **Library → Integrations**. To learn how imported data is stored, see [Transactions](/concepts/data-and-structure/transactions).

## Review connection impact

Before you add a connection, check which data it makes available to AI and who in the workspace can use it. Also check which actions it allows, such as reading versus writing.

Connections never widen access inside Oculon. People and agents can still only use resources they have permission to see. Admins set broader AI policy in [Workspace AI](/concepts/ai-and-agents/workspace-ai). To set up an agent, see [Create a custom agent](/concepts/ai-and-agents/custom-agents/create-a-custom-agent).
