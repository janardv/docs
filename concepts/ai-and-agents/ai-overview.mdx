AI in Oculon works inside your planning workspace. It reads the same models, boards, and Transactions you use, follows the same permissions, and can make changes for you with your approval.

## Ways to use AI in Oculon

The [AI assistant](/concepts/ai-and-agents/ai-assistant) is where most people start. It's a chat that everyone can use to ask questions, build models and boards, and explain results. When you find yourself typing the same instructions again and again, save them as a [skill](/concepts/ai-and-agents/skills) and run it from chat with `/`.

[Custom agents](/concepts/ai-and-agents/custom-agents) take over a repeatable job and run it on a schedule or on demand. Builders and admins usually set them up. Agents post their results and approval requests to [Feed](/concepts/ai-and-agents/feed), which everyone with access to an agent can see.

[Knowledge and memory](/concepts/ai-and-agents/knowledge-and-memory) covers what AI remembers about you, your projects, and your agents. [Context and connections](/concepts/ai-and-agents/context-and-connections) is where admins and builders bring outside tools into Oculon with plugins, or set up the Oculon MCP server. Admins set workspace-wide AI defaults and policy in [Workspace AI](/concepts/ai-and-agents/workspace-ai).

To use AI inside a project, see [AI in projects](/concepts/workspace-and-collaboration/projects-and-tasks/ai-in-projects).

## Which one should you use?

For a question or a one-off change, use the [AI assistant](/concepts/ai-and-agents/ai-assistant). If you want to review the approach before anything changes, switch to [Plan mode](/concepts/ai-and-agents/ai-assistant/plan-mode). For a larger outcome that takes many steps, use [Goal mode](/concepts/ai-and-agents/ai-assistant/goal-mode).

If you repeat the same prompt often, save it as a [skill](/concepts/ai-and-agents/skills). If the same job should run every week or month, build a [custom agent](/concepts/ai-and-agents/custom-agents).

To use Oculon from Claude, ChatGPT, or Cursor, connect the [Oculon MCP server](/concepts/ai-and-agents/context-and-connections/mcp).

## How Oculon keeps AI safe

AI can only see and change what you, or the agent, can access. High-risk changes, such as deletes and access changes, always need a person's approval. See [Approvals and checkpoints](/concepts/ai-and-agents/ai-assistant/approvals-and-checkpoints).

You can undo AI changes or restore an earlier checkpoint. The activity panel shows the sources and outputs behind each answer, so you can check how the AI got there.

## AI credits

AI use counts toward your workspace's AI Credits. Admins can see usage under **Settings → Admin → Usage**. See [Usage and limits](/concepts/settings-and-administration/billing-and-usage/usage-and-limits).
